# Pupil Labs recording exports

Wearable / Pupil Player exports for **blink**, **fixation**, and world-timeline teaching (Sessions 2–3).

| File | Role |
|------|------|
| `fixations.csv` | Fixation events (norm positions, duration, confidence) |
| `fixation_report.csv` | Summary report |
| `blinks.csv` | Blink events |
| `blink_detection_report.csv` | Blink detector summary |
| `world_timestamps.csv` / `.npy` | World-camera timeline |
| `annotations.csv` | Manual annotations |
| `export_info.csv` | Export metadata |
| `head_pose_tracker_*.csv` | Head-pose tracker outputs |
| `pupil_gaze_positions_info.txt` | Export field documentation |

Use alongside Tobii food data to contrast **screen-based** vs **wearable** pipelines.
