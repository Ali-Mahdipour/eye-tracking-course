# Tobii Pro Lab — GSR demo project

Screen-based Tobii exports used in **Sessions 3–4** (GSR + AOI/TOI metrics + behavior).

| File | Role |
|------|------|
| `Tobii_Pro_Lab_GSR_Demo_Project_Metrics.tsv` | Interval / AOI / pupil / GSR / mouse-click metrics (wide Tobii Metrics table) |
| `Tobii_Pro_Lab_GSR_Demo_Project_Data_Export.tsv` | Compact AOI summary export (multi-block layout) |

**Teaching hooks:** `Average_GSR`, `Number_of_SCR`, AOI dwell / TTFF, `Number_of_mouse_clicks.*`, `Last_key_press`, pupil diameter by AOI.

AOI labels in this demo include **Fruit / Mushroom / Snake / Spider** (threat-relevant search task).
