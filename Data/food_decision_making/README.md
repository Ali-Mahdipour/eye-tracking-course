# Food decision-making (Tobii Pro Lab)

Buy / not-buy food images with gaze, pupil, mouse, and AOI hits. Primary dataset for **Sessions 1–4**.

| File | Role |
|------|------|
| `Food_Decision_Making_Data_Export.xlsx` | Full sample-level export (gaze, pupil, mouse, events, AOI hits) |
| `Food_Decision_Making_Teaching_Sample.csv` | One recording (`Recording3`) extracted for fast classroom demos (IVT, heatmaps) |
| `Food_Decision_Making_Metrics.tsv` | Event-level metrics (fixations with AOI / pupil) |
| `Food_Decision_Making_Metrics.xlsx` | Tobii Metrics workbook (interval, fixation, visit, click sheets) |

**Stimuli overlays:** `Stimuli/Decision Making/` (`cake.png`, `pizza.png`, `ice-cream.png`, `cereal.png`, `date.png`, `fixation.png`).

**AOI naming examples:** `cake-pic`, `buy`, `not-buy` (and equivalents per food).
