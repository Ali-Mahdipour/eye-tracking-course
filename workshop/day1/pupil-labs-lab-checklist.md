## A. Before participants arrive (setup)

- [ ] Headset charged / powered; cables labeled
- [ ] Capture & Player versions noted: Capture ______  Player ______
- [ ] World / eye cameras show live image; focus acceptable
- [ ] Storage path set; free disk space OK
- [ ] Consent / lab rules posted; hygiene wipes available
- [ ] Demo task ready (e.g. look at 3 printed targets / short walk / screen poster)
- [ ] Backup USB + second headset plan confirmed with NBML staff

## B. Participant fit

- [ ] Explain what will happen in 30 seconds (no jargon)
- [ ] Adjust headset; eyes centered in eye cams
- [ ] Hair / glasses / makeup checked (glasses: try calibration carefully)
- [ ] Comfortable enough for full short recording

## C. Calibration & validation

- [ ] Launch calibration in Capture
- [ ] Participant follows targets; operator watches confidence / marker detection
- [ ] Calibration completes without obvious failure
- [ ] **Validation:** ask participant to look at 3 known points; gaze overlay looks right
- [ ] If validation fails → recalibrate once; if still fails → Contingency C1

## D. Recording

- [ ] Start recording **before** the critical event
- [ ] Annotate / note trial start time and condition on paper log
- [ ] Watch live: slip? pupil lost? scene dark?
- [ ] Stop recording cleanly; confirm folder created
- [ ] Write folder name on paper: ____________________________

- [ ] Open recording in Pupil Player
- [ ] Replay with gaze overlay
- [ ] Run fixation detector plugin (default params OK for first pass)
- [ ] Export: gaze CSV and/or fixations CSV to station folder
- [ ] Spot-check: timestamps increase; confidence not all zeros

## Contingency cards

**C1 — Calibration / validation fails**  
Recenter eyes → improve lighting → remove reflections → try 1-eye if needed → swap headset → use pre-recorded demo from NBML library for Player practice.

**C2 — Recording fails mid-trial**  
Stop → check disk/USB → restart Capture → shorter re-take. Do not overwrite the partial folder; label it `FAILED_partial`.

**C3 — Player cannot open recording**  
Confirm you are opening the recording **folder**, not a single file. Try another Player install / station. Fall back to shared demo recording for the export exercise.

**C4 — Time pressure**  
One good calibration + one short clean recording beats three messy ones. Move the group to Player on the demo recording; schedule individual re-takes in the buffer.
